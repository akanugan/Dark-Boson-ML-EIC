# Original BDT-versus-cuts study

**OLD STUDY ONLY:** these scans, independently repeated benchmarks, protocols, and checksum records describe the original two-method analysis. They do not contain the corrected three-method results.

Names such as `rigorous/final/` and `run_t_20260820_final/` identify completed historical stages. Current results are under [`revision/stratified_repair/`](../revision/stratified_repair/README.md), with ten independent runs at all eleven masses for both boson types.

Recorded files and method manifests are preserved unchanged. Larger original event/model artifacts are available in the [data-v1 release](https://github.com/iRojae/Dark-Boson-ML-EIC/releases/tag/data-v1); that release is not the current analysis.
