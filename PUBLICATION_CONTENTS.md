# Proposed public release

Destination: https://github.com/iRojae/Dark-Boson-ML-EIC

The repository contains simulation/analysis source code, configuration files, plotting and reproduction scripts, numerical summary tables, figures, protocol/provenance notes, and the current draft manuscript in LaTeX and PDF. The manuscript includes the authors' names, institutional affiliations, institutional email addresses, and unfinished author-contribution, funding, data-availability, and conflict declarations.

Release `data-v1` contains the complete `data/`, `models/`, and `fair_study/` trees: ROOT simulation events, event CSVs, trained TMVA models, bootstrap outputs, checksums, and historical development-run records. Local filesystem paths and run metadata may occur in provenance/log files. DATA_MANIFEST.csv lists each archived file, its size, and checksum.

Excluded: personal progress presentations/reports, Word manuscript drafts and backups, compiled executables, cached Python files, and third-party paper PDFs. External reference histograms are not redistributed.

The full simulation was not rerun for publication. This is a snapshot of the existing project, including historical records. Public access permits anyone to download and retain copies. No reuse license has been selected or added.
