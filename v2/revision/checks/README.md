# Recorded numerical checks

**CURRENT AUDIT RECORDS:** these files document source consistency, sampling-support checks, repairs, fitting settings, and statistical replay. Some compare an earlier configuration with its replacement. Historical absolute paths and timestamps identify the recorded execution; they are not instructions to run those paths locally.

`public_replay.json` records aggregate replay of the saved arrays. Figure reproduction is checked separately under [`../../figures/`](../../figures/README.md). Current result tables are under [`../stratified_repair/`](../stratified_repair/README.md), and [download instructions](../../DATA_DOWNLOAD.md) distinguish replay from event-level reproduction.
